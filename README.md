# 💸 Spend Story
### Every expense tells a story.

Spend Story is a personal expense tracking web application built using Python, Flask, and SQLite. It helps users track daily expenses, manage monthly budgets, plan upcoming expenses, and understand their spending habits through visual analytics.

## ✨ Features

- **Expense Management:** Add, edit, and delete expenses.
- **Dashboard:** View total expenses, monthly spending, and spending summaries.
- **Visual Analytics:** Category-wise expense breakdown and monthly spending charts.
- **Budget Management:** Set monthly budget goals and monitor budget usage.
- **Expense Planner:** Plan upcoming expenses and view projected spending.
- **Transaction Filters:** Search, filter, and sort expenses.
- **Responsive Design:** Clean interface designed for desktop and mobile screens.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/10Akshatha/Spend-Story.git
cd Spend-Story
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

### 3. Activate the environment

Windows:

```bash
.venv\Scripts\activate
```

### 4. Install Flask

```bash
pip install flask
```

### 5. Run the application

```bash
python app.py
```

Open your browser:

http://127.0.0.1:5000
